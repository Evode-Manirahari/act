# Pilot 0 — fifteen days, five cases

Blueprint Research Pilot 0. Duration is two to three weeks; this run is **15 days**.
The product loop is tested before more automation.

This is not the 60-day paid concierge in `PILOT.md`. Do not count demo-shop
rows, app tests, or this notebook as traction.

## Mix

Two callbacks, one near miss or verification failure, one difficult successful
diagnosis, one successful adaptation.

Debrief 5–7 minutes. Audio or notes are acceptable. Compile with the current
product. Publish only when provenance holds ([PR 81](https://github.com/Evode-Manirahari/act/pull/81)
/ [act-api 59](https://github.com/Evode-Manirahari/act-api/pull/59)).

## Days

| Days | Work |
| --- | --- |
| 1–2 | Consent, roster, callback definition, how dispatch is decided today |
| 3–10 | Capture and debrief the five episodes. Median debrief ≤7 min |
| 11–12 | Juniors commit before they see the expert. Schedule delayed variants |
| 13–14 | Manager names one coaching / supervision / dispatch change, or “no change” |
| 15 | Score the hypotheses. Continue, change, or stop |

Run the notebook at admin `/pilot`. It lives in the browser. Empty means empty.

## Pass lines (written before day 1)

See `PILOT0_HYPOTHESES` in `packages/domain/src/pilot0.ts`. A miss is not a

## What not to count

Minutes recorded. AI-generated cards. Founder prompt quality. Learner
satisfaction without a commit. Dashboard visits. One anecdotal callback.
